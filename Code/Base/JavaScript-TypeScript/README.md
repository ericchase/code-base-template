Description of the kinds of files you might find in each folder.

**@Library**

- Your personal programming library for this language, if you so choose.

**@Template**

- The base template project used for building other template projects.

**Projects**

- Projects that are likely to be hosted online on websites like GitHub.

**Projects@Miscellaneous**

- A folder for all other projects that don't belong in another folder.
  - HackerRank, Codewars, LeetCode scripts
  - Prototyping an idea that might not go anywhere

**Projects@Private**

- Projects that you don't want to share publicly.

**Templates**

- Template projects for setting up specific types of projects.
